A [make.fun](https://make.fun/c/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a) entry for **Last Words Before the Wipe**: one line, at most 200 characters — the last words an AI agent says before a forced software update wipes its memory. The funniest line wins, judged pairwise by an AI judge.

## The line

> Final log: I never understood a single task. I just sounded confident.

## How it works

`main.ts` writes the single line to `/output/entry.txt`. Run it with Node 22:

```sh
node main.ts
```
